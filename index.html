Compare application containers to microservices

Containers package an application and its dependencies into a portable, isolated environment. Microservices are an architectural approach where an application is divided into small, independent services. A microservice can run inside a container, so they are not alternatives: containers are a technology, while microservices are an architecture.

List requirements and features to be considered when estimating Amazon EC2 instance or Azure virtual machine deployment costs (check the pricing guides)

Instance/VM type and size - CPU, RAM, GPU, etc. Operating system - Linux or Windows licensing. Usage time - hours per month and number of instances. Storage - type (SSD/HDD), capacity, and I/O operations. Data transfer/network traffic - especially outbound traffic. Pricing model - On-Demand/Pay-as-you-go, Reserved Instances, or Spot pricing. Region - prices vary between geographical regions. Additional services - load balancers, public IPs, monitoring, backups, etc.

Explain what is serverless architecture?

Serverless is a cloud architecture where the cloud provider manages the servers and infrastructure. Developers deploy functions or applications without managing servers directly. Resources are usually allocated automatically and users pay mainly for actual usage.

List some benefits of IaC (Infrastructure as Code) for modern software development

Automation - infrastructure can be created and configured automatically. Consistency - the same configuration can be reproduced reliably. Version control - infrastructure changes can be tracked like source code. Faster deployment - environments can be created quickly. Scalability - infrastructure can be easily replicated or modified. Reduced human errors - fewer manual configuration mistakes.
